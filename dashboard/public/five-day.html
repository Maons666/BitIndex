五日对照统一说明

表格如何对应

预测起点为 D，第 1～5 天分别是 D+1 至 D+5 的 UTC 日收盘价。五个预测价在发出时同时冻结，每一期使用同一信息截止点，不会随着后面的实际价格重算。实际价按精确目标日填入；缺失时保持“待公布”，未到期显示“未到期”。同一天可能对应不同起点、不同预测期限，分别保留，不合并。

偏差 =（预测 / 实际 − 1）×100%；正数表示高估，负数表示低估。MAPE 为相同期限所有已配对目标的绝对偏差平均值；与不加事件、不变价基线比较时使用同一批实际日期。收益窗口重叠，不代表独立试验。

当前模型与 agent

沿用事件模型的趋势、波动与事件收缩公式，新增独立的 event-scenarios-1to5-v1 版本。每个期限直接计算目标价，不把原 7 天或 30 天预测插值成五天。趋势来自近 7/28 日日收益，波动取近 28/60 日较大值；历史事件按各自 1、2、3、4、5 天窗口分别分级，且只使用截止点之前已经完成的观察窗口。没有同类样本时事件贡献为零，未知风险仍保留在证据说明中。

每天的免费定时任务在行情成功更新后生成当日新一期，沿用最近一次已签发的 agent 事件判断，并按事件真实年龄衰减；不会自动调用付费模型，也不会把旧分析标成当天重新核查。Agent 分析超过 7 天、行情过旧或缺日时暂停新增，已有实际对照继续更新。需要你在对话中触发 agent 更新研究；原来的 7/30 天及 Ridge 留档不改变。一个 UTC 日期只保留首次签发，不补造错过日期的真实预测。

历史回放

历史表按起点当日 16:00 UTC 模拟，行情保守滞后 2 个日历日；事件按当时已经公开且可用的信息截断，同一新闻流只保留最新状态。只知道发布日期的事件延至次日 12:00 UTC 使用。首批的第 5 天目标覆盖此前选定的 30 个实际日期，每个起点另有前 4 天的对照，因此共 150 条预测—实际配对。

这是今天重建的回测，未声称过去实际发出。模型、案例选择和 agent 判断仍有事后偏差；行情使用当前下载历史版本，无法完整还原当年的数据修订与发布时刻。历史回放与真实留档分开统计，数据、证据和实际重建时间保存在独立目录。完整来源可在每期证据及 JSON 中查看。
