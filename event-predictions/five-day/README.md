# 每日未来五天预测

独立页面 `five-day.html`。每个 UTC 起点一次性生成 D+1 至 D+5 的五个目标，随后按精确目标日的首次实际记录结算。不同起点即使指向同一目标日，也各自保留。当前模型为 `event-scenarios-1to5-v1`，沿用原事件模型公式，但案例窗口分别按 1、2、3、4、5 天测量，不插值旧预测。

- `forecasts/<id>.json`：实际签发的首期种子，含模型输出、完整计算输入、原始 agent 分析 ID 与截止时间。读取时按真实签发时间复算。
- `replays/<id>.input.json` / `.report.json`：冻结的历史研究包及回放；与真实预测分开统计，读取时复算。首批 30 个起点为 2026-10-09 至 11-07，第五天目标为 10-14 至 11-12，共 150 个配对。
- 数据分支 `tracking-data` 的 `predictions/five-day/forecasts`：每日新预测，仅首次签发写入。
- 数据分支 `predictions/five-day/comparisons`：各期限精确目标日的首次实际值，不回写修订。

## 免费日更

既有 GitHub Actions 每天成功获取行情后运行 `node dashboard/update-five-day.mjs --issue`。它读取最近一次由 agent 实际签发的研究，保留原分析时间，用今日行情及按实际消息年龄衰减的事件权重生成五个目标。不会自动调用 LLM，也不假称当天重新核查新闻。Agent 分析超过 7 天、行情获取超过 24 小时、日线缺日或基准过旧时暂停新增；已有预测继续对照。不补造过去错过的签发日。代码推送仅部署及核对实际，不额外生成预测。

同一 UTC 日期重复或并发调用不会改写首次目标。用户在对话中触发新的事件分析并发布后，下次日更自动采用新研究。原 Ridge 的 14 份与原 7/30 日事件预测保持不变。

## 历史回放限制

截止点为起点当日 16:00 UTC，行情假定滞后 2 天。Agent 研究按历史原文重建；事件只在其可用时间之后使用，同一新闻流取最新状态。案例分级只使用截止点前的行情及已完成窗口。真实重建与核查时间均保留，不伪装历史签发。

模型、案例选择和 agent 观点均在今天形成，存在事后偏差。行情属于当前下载版本，无法完整还原服务商历史修订和可用时刻。各期限收益窗口重叠，不能当成独立试验。每个期限独立报告相同配对样本上的 MAPE 和两种基线，未到期不计误差。原 30 天回放留作旧实验，不滚动覆盖。
